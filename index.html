The Story

We built what we needed

Mobile repair shops in Zanzibar were running the same workflows as shops anywhere else, but the tools available to them weren't close. SalemDomain MobileTech started as a practical answer to that gap.

Every screen you see was designed around the actual rhythm of a repair bench. The billing engine charges once per device's hardware identifier, so the same phone never gets billed twice. The log shows you exactly what happened, step by step, in real time, with no post-hoc guessing.

We're part of the ZIVO community, the Zanzibar Internship & Volunteer Organization, and we think technicians on the Indian Ocean coast should have the same quality tools as anyone in London or Nairobi.

The Flow

Same four steps, every time

We made it consistent on purpose. Once you've done one service, you know how all of them work.

1

Connect & detect

Plug the device in. The platform reads the USB descriptor immediately: brand, model, chip, mode, iOS version, activation state. No waiting, no manual entry.

2

Pair if needed

For Normal Mode services, the app handles pairing automatically. If the pairing record is stale, it repairs it. If the device needs to show a Trust prompt, it waits for you to tap it.

3

Charge once

The service charge is tied to the device's hardware identifier. Same device on a second visit? The app recognises it, skips the charge, and runs the service anyway. You're billed for work, not for repeat submissions.

4

Run & clean up

The service runs. Every step is logged to the panel in real time. When it's done, whether success or failure, temporary files are removed and the log is written. The bench stays clear.

Platform Details

The parts that matter

Some platform decisions that might not be obvious from the outside but make a real difference day-to-day.

Real-time step log

Every service logs each step as it happens, with timestamps and status tags. No spinner and hope.

Resumable downloads

Large ramdisk files download in parts. If the connection drops, the next run resumes from exactly where it stopped.

Silent auto-updater

Checks for new versions on every launch. Updates install quietly, and you start the updated version next time you open the app.

Event-driven USB detection

No polling. The platform listens for real OS-level device events, and the panel updates the moment a device connects or changes mode.

Role-based access

Separate views and permissions for superusers and technicians. Documents and admin panels are only visible to accounts that should see them.

Dark & light mode

Both modes use the same brass/navy palette. Preference is saved locally and applied immediately on the next launch, splash screen included.
